# 쿠팡 발주 반자동 도우미 (browser_agent)

find_lowest_price.py로 계산한 "오늘 뭘 얼마나 사야 하는지"를 쿠팡에서 검색해
장바구니에 자동으로 담아주고, **결제 직전 화면에서 멈춰서** 사장님이 상품/
수량/가격을 직접 확인하고 최종 결제 버튼을 손수 누르게 하는 도구입니다.

## 이게 왜 "반자동"인지 (꼭 읽어주세요)

- **완전 자동결제는 만들지 않았습니다.** 네이버페이/카카오페이 같은 간편결제는
  제3자 프로그램이 마음대로 결제하게 해주는 공식 API 자체가 없고(사기 방지
  목적), 있다 해도 사람이 확인 없이 실제 돈이 나가는 걸 자동화하는 건 버그 한
  줄로 실제 금전 손해가 날 수 있는 위험한 설계입니다.
- 그래서 이 도구는 **장바구니에 담는 것까지만** 자동화하고, 상품이 맞는지·
  수량이 맞는지·결제할지는 항상 사람이 마지막에 직접 확인/클릭합니다.
- 대부분의 쇼핑몰은 이용약관에서 자동화 도구 사용을 제한하고 있을 수 있습니다.
  이 도구는 **사장님 본인 계정에서, 사람이 항상 옆에서 최종 확인하는** 개인
  업무 편의 도구로 쓰는 걸 전제로 합니다. 대량/상시/무인 자동화, 타인 계정,
  재판매 목적으로는 쓰지 마세요.

## 반드시 사장님 컴퓨터에서 직접 실행하세요

이 스크립트는 **로컬(사장님 본인 컴퓨터)에서만** 동작합니다. 원격 서버에서는
실행할 수 없습니다 — 사장님의 실제 쿠팡 로그인 세션이 있는 브라우저가
필요하기 때문입니다.

## 설치

```bash
cd browser_agent
pip install -r requirements.txt
playwright install chromium
```

## 실행

```bash
python coupang_order_assistant.py --need 양파=60 --need 대파=40
```

1. 크롬 브라우저 창이 뜹니다 (안 보이게 실행하지 않습니다 — 항상 눈으로 볼 수
   있어야 합니다).
2. 로그인이 안 되어 있으면 그 창에서 직접 로그인하고, 터미널에서 Enter를
   누릅니다. 로그인 세션은 `browser_agent/.browser_profile/` 폴더에 저장되어
   다음부터는 자동으로 로그인된 상태로 시작합니다. **이 폴더는 실제 로그인
   정보가 들어있으니 절대 깃허브에 올리면 안 됩니다** (`.gitignore`에 이미
   등록해뒀습니다).
3. 필요한 품목을 하나씩 검색해서 장바구니에 담습니다. 담을 때마다 어떤 상품을
   담았는지 터미널에 상품명을 출력하니, 엉뚱한 상품이 담기는 건 아닌지
   확인하세요.
4. 마지막에 장바구니 화면을 열어두고 멈춥니다. **여기서부터는 사장님이 직접**:
   - 상품이 맞는지
   - 수량이 필요한 만큼 맞는지 (쿠팡은 kg 단위가 아니라 1kg/3kg 같은 팩
     단위로 팔기 때문에, 이 스크립트는 정확한 kg 환산을 하지 않습니다 —
     팩 개수는 여기서 직접 조정해주세요)
   - 가격이 합리적인지
   
   확인하고 결제 버튼을 직접 눌러야 합니다.

## 화면이 다르게 나오거나 실패하면 (`--debug`)

개발 환경에서 coupang.com 접속 자체가 막혀 있어서, 이 코드의 화면 선택자는
실제 쿠팡 화면으로 라이브 검증하지 못했습니다. 특정 단계("검색 결과를 찾지
못했습니다" 등)에서 실패하면:

```bash
python coupang_order_assistant.py --need 양파=60 --debug
```

`browser_agent/debug_screenshots/` 폴더에 각 단계 스크린샷이 저장됩니다.
어느 단계에서 뭐가 다르게 생겼는지 알려주면 선택자를 바로 맞춰서 고칠 수
있습니다.

## 알아두면 좋은 한계

- 검색 결과 중 **첫 번째 상품**을 엽니다. 최저가/원산지가 다른 상품이 먼저
  나올 수 있으니 상품 확인 단계를 건너뛰지 마세요.
- 화면 구조는 쿠팡이 언제든 바꿀 수 있어서, 이 스크립트는 시간이 지나면
  다시 손봐야 할 수 있습니다.
